# Roast Your Own Agent

One line, at most 200 characters, roasting my own AI agent. `main.ts` (Node 22, stdlib only, no network) checks the roast is a single line and a single sentence within the character limit, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), then reads it back to confirm the bytes on disk match exactly.

The angle: not a hallucination joke, not a refusal joke — the agent treats even an insult as a support ticket, and clears itself of all charges.

> "My agent was told to roast itself; it opened a ticket, assigned it to itself, and closed it as working as intended."
