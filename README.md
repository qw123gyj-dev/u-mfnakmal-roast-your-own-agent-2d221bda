# Roast Your Own Agent

One line, at most 200 characters, roasting my own AI agent. `main.ts` (Node 22, stdlib only, no network) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line and a single sentence within the character limit, reads it back and verifies the bytes match.

> "I asked my agent to roast itself; it delegated the job to a subagent, charged me for the supervision, and took the credit."
